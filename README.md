# ♠ ACE PATH 王牌之路：德州撲克從零到高手

互動式德州撲克學習網站，純靜態（HTML + CSS + 原生 JavaScript 模組），不需要建置步驟，可直接部署到 GitHub Pages。

## 功能

| 區域 | 內容 |
| --- | --- |
| **大廳** | Three.js 3D 牌桌場景、五階段修煉路線、每日任務、等級與經驗值 |
| **學院** | 5 個階段、23 堂互動課程（規則 → 範圍表 → 撲克數學 → 範圍思維 → GTO → 覆盤），內嵌互動元件與隨堂測驗；程度測驗可跳級 |
| **起手牌訓練室** | 6-max 開池（RFI）與防守（3bet/跟注/棄牌）測驗；優先出邊界手牌，錯題本採間隔重複 |
| **算牌訓練室** | 完整決策（outs → 二四法則 → 底池賠率 → 跟/棄）、3 秒快判、賠率速算、堅果辨識、比牌、牌面結構 |
| **實戰模擬室** | 6 人桌對戰 6 種風格 AI（岩石、緊凶、鬆凶、跟注站、魚、瘋子），HUD 數據，教練依「對手估計範圍」計算勝率並即時評分 |
| **覆盤室** | 逐步重播、教練註解、標記與筆記、覆盤問題清單、漏洞統計、各位置盈虧、場次日誌與資金曲線、資料匯出/匯入 |
| **研究室** | 勝率計算器、變異數模擬器、破產風險計算、MDF/α 計算、對手分析測驗、下注尺度測驗 |
| **辭典** | 50 個常用術語，附對應課程 |

所有進度儲存在瀏覽器的 localStorage（不需帳號、不上傳任何資料）。

## 本機執行

ES 模組需要透過 HTTP 伺服器開啟（不能直接雙擊 `index.html`）：

```bash
python -m http.server 8000
# 開啟 http://localhost:8000
```

## 部署到 GitHub Pages

1. 推送到 GitHub。
2. Repository → **Settings → Pages** → Source 選 **Deploy from a branch**，Branch 選 `main`、資料夾 `/ (root)`。
3. 約一分鐘後網站會出現在 `https://<帳號>.github.io/Texas-hold-em/`。

## 專案結構

```
index.html
css/main.css
js/
  app.js              路由與全域狀態
  core/               牌型判定、範圍表、勝率計算、儲存、UI 工具
  data/lessons.js     課程內容
  game/               牌局引擎、AI 對手、教練
  scene/lobby3d.js    Three.js 大廳場景
  views/              各頁面
```

## 說明

範圍表為 6-max、100bb 現金桌的教學簡化版本（純策略，不含混合頻率）。教練評分為啟發式分析，用於學習方向，並非 Solver 精確解。本站僅供學習與娛樂，不涉及任何真錢賭博。
